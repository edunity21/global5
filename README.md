# BRIDGE-AI 면접 발표 리허설 (5분)

2026 인공지능 활용 선도교사 글로벌연수 면접 발표를 슬라이드·대본·타이머와 함께 연습하는 웹페이지입니다.

## GitHub Pages에 올리기
1. GitHub에서 새 저장소를 만듭니다.
2. **Add file → Upload files**로 이 폴더의 `index.html`, `deck.js`, `README.md`, `slides` 폴더를 그대로 끌어다 놓고 Commit 합니다.
3. **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 로 접속합니다.

> 카메라·마이크는 https 주소에서만 켜집니다(GitHub Pages는 https).

## 클리커(USB 동글)
동글을 꽂으면 키보드로 인식되어 바로 동작합니다(Page Down/Up, 방향키, F5, B 등).
반응하지 않는 버튼은 상단 **클리커** 메뉴 → ‘버튼 등록’ 후 그 버튼을 누르면 됩니다.
신호는 선택된 브라우저 창으로만 들어오므로, 다른 프로그램을 눌렀다면 화면을 한 번 클릭하세요.

## 파일 구성
- `index.html` — 화면과 기능
- `deck.js` — 슬라이드 제목·대본·발표 시간(기본 5분). 대본을 고치면 장별 목표 시간도 다시 나뉩니다.
- `slides/01.jpg ~ 15.jpg` — 슬라이드 이미지(1920×1080)

### 슬라이드 이미지를 원본 그대로 바꾸려면
PowerPoint → 파일 → 내보내기 → 파일 형식 변경 → JPEG → ‘모든 슬라이드’로 저장한 뒤,
`슬라이드1.JPG` → `01.jpg` 처럼 이름을 바꿔 `slides` 폴더에 덮어쓰면 됩니다.
